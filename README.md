## ⚡ Key Features

- **Integrated Reader Wrapper**: Browse any of the 1,200 chapters with an app-level stepper (`‹` / `›`), table of contents drawer, chapter progress bar, and keyboard shortcuts (`←`, `→`, `Esc`).
- **Offline & Private Progress**: Chapter completion is tracked automatically using browser `localStorage`. No accounts, no cookies, no tracking.
- **Responsive Dark/Light Study Mode**: Thoughtfully styled with high-contrast warm slate, cream typography, and subtle ambient tones.
- **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript. Runs directly in any modern browser without npm, node, or build tools.

## 🚀 Running Locally

Clone the repository and open `index.html` directly:

```bash
git clone https://github.com/harshdotcom/AI-Systems.git
cd AI-Systems
```

Open `index.html` in your browser:
```bash
# Linux
xdg-open index.html

# macOS
open index.html

# Or serve via Python
python3 -m http.server 8000
```
